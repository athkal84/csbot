
UNIT 7 — Συνεργατικά Έγγραφα Google Docs

1. Τι είναι τα συνεργατικά έγγραφα
Τα συνεργατικά έγγραφα είναι αρχεία που επιτρέπουν σε πολλά άτομα να γράφουν και να επεξεργάζονται ταυτόχρονα.
Οι μαθητές μπορούν να γράφουν, να διορθώνουν, να σχολιάζουν και να βλέπουν αλλαγές σε πραγματικό χρόνο.

2. Πώς μπαίνω στο Google Docs
Για να χρησιμοποιήσεις το Google Docs χρειάζεσαι λογαριασμό Google.
Ανοίγεις το Google Drive → Νέο → Έγγραφο Google.

3. Πώς γράφω και μορφοποιώ κείμενο

Πώς μπορώ να κάνω έντονα γράμματα;
Επίλεξε το κείμενο → Ctrl + B ή το κουμπί Έντονα.

Πώς μπορώ να κάνω πλάγια;
Επίλεξε το κείμενο → Ctrl + I ή το κουμπί Πλάγια.

Πώς μπορώ να υπογραμμίσω;
Επίλεξε το κείμενο → Ctrl + U ή το κουμπί Υπογράμμιση.

Πώς αλλάζω χρώμα;
Επίλεξε κείμενο → Χρώμα κειμένου → διάλεξε χρώμα.

Πώς αλλάζω μέγεθος γραμματοσειράς;
Επίλεξε κείμενο → Μέγεθος γραμματοσειράς → διάλεξε αριθμό.

4. Πώς εισάγω αντικείμενα

Πώς εισάγω εικόνα;
Εισαγωγή → Εικόνα → διάλεξε πηγή.

Πώς εισάγω πίνακα;
Εισαγωγή → Πίνακας → επίλεξε γραμμές και στήλες.

Πώς εισάγω σύνδεσμο;
Επίλεξε λέξη → Ctrl + K → βάλε σύνδεσμο.

5. Συνεργασία

Πώς μοιράζομαι το έγγραφο;
Κοινή χρήση → γράψε email → επίλεξε δικαιώματα.

Πώς βλέπω ποιος έκανε αλλαγές;
Αρχείο → Ιστορικό εκδόσεων.

Πώς γράφω σχόλιο;
Επίλεξε σημείο → Σχόλιο.

Πώς κάνω προτεινόμενες αλλαγές;
Κατάσταση επεξεργασίας → Προτεινόμενες αλλαγές (Suggesting).

6. Χρήσιμες λειτουργίες

Πώς κάνω αριθμημένη λίστα;
Επίλεξε κείμενο → Αριθμημένη λίστα.

Πώς κάνω κουκκίδες;
Επίλεξε κείμενο → Λίστα με κουκκίδες.

Πώς βρίσκω μία λέξη;
Ctrl + F.

7. Αποθήκευση και αρχεία

Πώς αποθηκεύω;
Αποθηκεύεται αυτόματα.

Πώς κατεβάζω PDF;
Αρχείο → Λήψη → PDF.

Πώς κατεβάζω Word;
Αρχείο → Λήψη → Microsoft Word (.docx).
