ΕΝΟΤΗΤΑ 3 – ΤΟ ΕΣΩΤΕΡΙΚΟ ΤΟΥ ΥΠΟΛΟΓΙΣΤΗ
=====================
ΘΕΩΡΙΑ
=====================

3.1 Εισαγωγή
Ο υπολογιστής αποτελείται από πολλά μέρη. Στο εσωτερικό της Κεντρικής Μονάδας βρίσκονται τα βασικά εξαρτήματα που συνεργάζονται για να εκτελούν εργασίες γρήγορα και σωστά.

Κύρια εξαρτήματα:
- CPU: επεξεργάζεται εντολές. Παράδειγμα: όταν ανοίγεις ένα παιχνίδι, η CPU κάνει τους υπολογισμούς του.
- RAM: προσωρινή μνήμη για όσα χρησιμοποιούνται εκείνη τη στιγμή.
- Motherboard: συνδέει όλα τα εξαρτήματα.
- Αποθηκευτικά μέσα: HDD, SSD για μόνιμη αποθήκευση.
- Κάρτα γραφικών: δημιουργεί την εικόνα.
- Τροφοδοτικό: δίνει ρεύμα.
- Σύστημα ψύξης: προστατεύει από υπερθέρμανση.

3.2 Ο προσωπικός υπολογιστής εσωτερικά

Τροφοδοτικό (PSU)
Δίνει την απαιτούμενη ισχύ σε κάθε μέρος του υπολογιστή.
Παράδειγμα: Αν χαλάσει το τροφοδοτικό, ο υπολογιστής δεν ανοίγει.

Μητρική πλακέτα (Motherboard)
Πάνω της συνδέονται όλα τα βασικά εξαρτήματα: CPU, RAM, κάρτες επέκτασης, θύρες, δίσκοι.

Κύρια μέρη:
- CPU Socket
- Θέσεις RAM
- Chipset
- BIOS/UEFI
- PCIe υποδοχές
- Θύρες I/O (USB, HDMI κ.ά.)
- SATA και M.2 για δίσκους

Παράδειγμα: Για να τοποθετηθεί ένας γρήγορος SSD, χρησιμοποιούμε τη θύρα M.2.

Επεξεργαστής (CPU)
Ο “εγκέφαλος” του υπολογιστή. Εκτελεί εντολές και κάνει υπολογισμούς.
Παράδειγμα: Όταν παίζεις παιχνίδι, η CPU υπολογίζει την κίνηση και τις ενέργειες.

Κύρια μνήμη – RAM και ROM

RAM:
- Προσωρινή μνήμη
- Γρήγορη πρόσβαση
- Χάνεται όταν κλείσει ο υπολογιστής
Παράδειγμα: Αρκετές καρτέλες στο πρόγραμμα περιήγησης γεμίζουν τη RAM.

ROM:
- Μόνιμη μνήμη
- Περιέχει το BIOS/UEFI για την εκκίνηση του υπολογιστή
Παράδειγμα: Κάθε φορά που ανοίγει ο υπολογιστής, η ROM εκτελεί τους αρχικούς ελέγχους.

3.3 Εσωτερικές κάρτες

Κάρτα γραφικών (GPU)
Παράγει εικόνες και βίντεο.
Παράδειγμα: Τα παιχνίδια 3D χρειάζονται καλή GPU.

Κάρτα ήχου
Αναλαμβάνει μικρόφωνο και ηχεία.
Παράδειγμα: Η μουσική ακούγεται χάρη στην κάρτα ήχου.

Κάρτα δικτύου
Επιτρέπει σύνδεση στο δίκτυο.
Παράδειγμα: Για σύνδεση στο σχολικό δίκτυο χρησιμοποιούμε κάρτα δικτύου.

Κάρτες επέκτασης (PCIe)
Προσθέτουν νέες δυνατότητες.
Παράδειγμα: Μπορείς να εγκαταστήσεις κάρτα WiFi.

3.4 Θύρες σύνδεσης

Οι θύρες είναι υποδοχές που επιτρέπουν τη σύνδεση εξωτερικών συσκευών.

Κύριες θύρες:
- USB (2.0, 3.0, 3.1, USB-C)
- Ethernet (RJ-45)
- Θύρες ήχου (ακουστικά, μικρόφωνο)
- VGA / DVI
- HDMI / DisplayPort
- eSATA

Παράδειγμα: Για οθόνη υψηλής ανάλυσης χρησιμοποιούμε HDMI ή DisplayPort.


3.5 Πίνακας χαρακτηριστικών

| Χαρακτηριστικό | Περιγραφή |
|----------------|-----------|
| CPU            | Επεξεργαστής |
| RAM            | Μνήμη RAM |
| GPU            | Κάρτα γραφικών |
| Κάρτα ήχου     | Αναλαμβάνει ήχο |
| Κάρτα δικτύου  | Επιτρέπει σύνδεση στο δίκτυο |
| Κάρτες επέκτασης | Προσθέτουν νέες δυνατότητες |
| Θύρες σύνδεσης | Επιτρέπουν σύνδεση εξωτερικών συσκευών |


Παράδειγμα: Η CPU είναι ο "εγκέφαλος" του υπολογιστή.
